# REIT — Real Estate Investing Tool

## Goal
Claude-powered tool that pulls NZ property listings, ranks them across key quality/potential dimensions, and includes financial calculators.

## Core Features

### Listings Analysis
- Pull recent sales + listings from real-estate NZ
- Rank each property across:
  - House quality + upside potential
  - Land quality + upside potential
  - Area quality + growth potential
- Show current rent vs potential rent
- Flag best opportunities automatically
