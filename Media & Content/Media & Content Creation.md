# Media & Content Creation

## TWLN — Local News Network Concept

**Format:**
- 2 hosts, 2 producers
- Target audience: 4M–10M
- Affiliates in all regions sharing profits

**Content segments:**
- 7-min weekly wrap-up of events (post links to each story)
- 20-min cover of local issues / council planning
- Provincial / federal politics (in smaller countries)
- Local business issues
- Technological / monetary / administrative solutions
- How people can get involved to fix issues

**Website:**
- Map interface to view all regions
- Videos + transcripts for each week, per region
- News page per region
- Alerts for important regional stories

**Social media strategy:**
- Twitter account per region — tweet stories
- Facebook page per region — update stories
- Snapchat for on-air personalities
- Notify app — direct stories to subscribers

**Coverage scale:** Neighbourhood → Municipal → Regional → Provincial → National
