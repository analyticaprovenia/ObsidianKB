## Data Science & Privacy Engineering

### De-identification Techniques
- Tokenisation, hashing, pseudo-anonymisation
- UDF + multi-column UDF
- Numeric, text, date, name handling
- Grouping / make bins
- Regex-based de-id
- Create pseudo-IDs and store in domain
- **Differential privacy**: add noise to distribution on numeric columns
- One-hot encoding for small cardinality → re-encode
- **K-anonymity** for other columns
- Parameterise top/bottom bounds depending on sensitivity
- Investigate combined k-anon + differential privacy
- Multiple releases / WIG (Worst-case Information Gain)

### Data Profiling
- Familial relations
- Oracle databases
- Compound primary keys
- Linked data tables
- CSV file handling
- Textual de-id
- Bias in data
- Differential privacy

## Mindset & Self-Development

### Common Blockers (and responses)
- **Indifference** → care about what you're doing, do it best
- **Indecision** → make a decision; you'll find out sooner
- **Doubt** → eliminate self-doubt
- **Over-caution / timidity** → not doing it is also a risk; give it a go
- **Pessimism** → don't try to figure out what's wrong — figure out what's right
- **Analysis paralysis** → doubt kills more dreams than failure does

### Target Traits
Motivated · Confident · Decisive · Bold
